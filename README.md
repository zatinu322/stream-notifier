## Installation

Library installation is only available from this Github repository.

It is recommended to install library via `uv`:

```shell
uv add "git+https://github.com/zatinu322/stream-notifier@main"
```

Alternatively you can use `pip`:

```shell
pip install "git+https://github.com/zatinu322/stream-notifier@main"
```
